CalcNova - Consistent Workspace Padding

1. Extract this folder.
2. Open PowerShell in the extracted folder.
3. Install dependencies:
   python -m pip install -r requirements.txt
4. Run:
   python main.py

Changes in this update:
- Reduced excess right-side inset in the calculator and scientific toolkit.
- Applied consistent, slightly compact outer padding to Calculator, GST & %, Currency, and History.
- Standardized internal spacing and kept the existing pastel glass theme and moving particles.
